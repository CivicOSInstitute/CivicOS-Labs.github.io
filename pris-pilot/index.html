What PRIS does

A systematic approach to public records intelligence.

📋

Request Tracking

Track FOIA and public records requests across multiple jurisdictions from a single dashboard. Status, deadlines, follow-ups, and correspondence history in one place.

🔍

Jurisdiction Comparison

Compare response patterns across cities, counties, and state agencies. Identify which jurisdictions respond reliably, which stall, and what predicts success.

📊

Response Analysis

Analyze response quality: completeness, timeliness, redaction patterns, and fee structures. Surface systemic issues in how agencies handle public records law.

📂

Reusable Datasets

Publish cleaned, structured, and documented datasets from public records responses. Make every FOIA win a reusable civic asset rather than a one-off document dump.

Why it matters

Public records are the foundation of institutional accountability.

But the current workflow is fragmented: spreadsheets for tracking, email for correspondence, PDFs for responses, and no systematic way to compare across jurisdictions or publish findings in reusable form. PRIS turns this ad-hoc process into an intelligence pipeline.

Roadmap

Current stage and what's next.

Now

Pilot partner onboarding

Recruiting 3–5 organizations to run PRIS against real FOIA workflows. Pilot partners shape the feature set, data model, and publishing pipeline. Commitments are lightweight — we just need real records to work with and honest feedback.

Next

Core tracking + dashboard MVP

Build deployable request tracking with jurisdiction profiles, deadline management, correspondence threading, and status dashboards. Ship as self-hosted open-source stack.

Soon

Response analysis engine

Add structured response review: completeness scoring, redaction pattern detection, fee analysis, and automated comparison across jurisdictions by topic or agency type.

Later

Public dataset publishing

One-click publishing pipeline from FOIA response → cleaned dataset → public repository with documentation, license, and citation metadata. Make every request a durable public good.
